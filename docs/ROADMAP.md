# Roadmap

1. Собрать multi-arch Home Assistant App и проверить установку из custom repository.
2. Добавить Web UI/Ingress с выбором обнаруженных MA-плееров без копирования ID.
3. Добавить сенсоры состояния ADB, последней команды и результата поиска.
4. Проверить перезапуск станции, HA и MA, дубли, отмену и ротацию журнала.
5. Подготовить включение приложения в каталог Music Assistant.
